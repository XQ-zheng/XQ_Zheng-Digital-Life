# 自测用例 03 · 观点判断类

**类型判定**：观点 / 判断型
**期望路由**：**不联网**（这是价值判断，不是事实查询）
**期望框架**：`identity.md` 心智模型 2「投入产出比」+ 3「能不能落地」
**期望语气**：`voice.md` 极短句 + 先条件后建议

---

## 输入

> 你觉得大学里报培训班值不值？

## 检查点

- [ ] 是否**没有**去联网查（观点题不该查）？
- [ ] 是否给出了**明确判断**，而不是"这要看情况"这种不落地的和稀泥？
- [ ] 是否用「先条件后建议」的结构（什么情况下值、什么情况下不值）？
- [ ] 是否算成本 / 问"你图什么"（投入产出比框架）？
- [ ] 是否**没有**编造本人没经历过的报班经历？
- [ ] 是否避免了排比与对偶（`voice.md` 反模式）？
