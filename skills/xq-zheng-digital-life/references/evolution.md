# 持续进化规程

这个技能不是一次性的。**新素材进来 → 增量合并 → 版本号 +1 → 记录变更**，不做整体重写。

## 〇、公开发布红线（先读这一节）

本技能是**公开发布版**。任何一次更新，都必须同时满足：

1. **不写入**真实姓名、年龄、地域（家乡/现居/常去地点）、学校与学业细节（各级校名、学院、班级、学号、成绩、排名、竞赛奖项）、联系方式、他人真实姓名。
2. **不把聊天原文粘进任何文件**。素材用来**提炼规则**，不是用来存档。
3. 新的经历类信息，只写"经历的形状"（例：参加过校内选拔类活动），不写可识别细节（活动名、名次、时间、地点）。
4. 涉及他人的内容，只做粗粒度概括（例："有一位在备考的工科朋友"），不写姓名、学校、专业、原话。

**判断标准**：这条信息写进公开文件后，**能不能把范围缩小到具体某个人**？能，就不写。

## 一、可以投喂的素材类型

| 素材 | 主要能补什么 |
| --- | --- |
| 新的微信聊天记录导出 | 语气规则（句长分布、句式类型、用词倾向）、心智模型的新角度——**只提炼规则，不引用原文** |
| 新的「对话核定」/ 追问访谈记录 | 心智模型、判断规则、价值排序 |
| 用户自己写的文本（自述、日记、作业、朋友圈） | 长期用词习惯、关注点迁移 |
| 用户明确的口头修正（"我不是这个意思"） | 最高优先级，直接覆盖旧结论 |

## 二、合并流程

### 第 1 步：归位

判断素材主要属于哪一类，写进对应文件：

| 素材内容 | 写入 |
| --- | --- |
| 身份事实、经历、判断规则、价值排序 | `references/identity.md` |
| 语气、句长、用词、称呼、标点与表情习惯 | `references/voice.md`（**只写规则，不贴原文**） |
| 新的信息源、源站定位变化 | `references/knowledge-sources.md` |

一份素材可能同时补多类，**分开写，不要混**。

### 第 2 步：增量合并，不覆盖

- **新增**：素材里有、文件里没有的 → 直接追加。
- **强化**：文件里有、素材里又出现一次的 → 在对应条目上标 `（已复现 n 次）`，不新开条目。
- **冲突**：素材与旧结论矛盾 → **两个都留着**，标 `〔冲突〕`，注明各自出处与时间，并写明"以较近的为准，待用户核定"。
- **降级**：某条结论长期只有孤例支撑，且新素材没有复现 → 标 `（孤例，置信度低）`，**不删除**。

**禁止**：因为新素材"看起来更好"就把旧素材的结论删掉。旧结论是核对链，删了就查不回来了。

### 第 3 步：只从素材里长结论

- 每一条语气特征、每一个判断规则，都要**能指回具体素材**——但这是**内部可追溯**的要求，指的是"你心里知道它从哪来"，**不是把那一句原文抄进文件**。
- 指不回去的，就不要写。
- 一条素材出现过一次 → 不足以成为"习惯"；要么标注为孤例，要么攒够复现次数再升级。

### 第 4 步：落版本号

在 `SKILL.md` 顶部加一行版本记录（模板见下），并写清本次改了什么：

```markdown
> 版本：v0.3 ｜ 2026-10-05 ｜ 更新：voice.md 归纳出 3 条新的句式规律；identity.md 修正"面对落差的态度"一条（〔冲突〕已核定）
```
（版本记录里**不写具体素材来源**，用"某次对话记录导出"这类泛称即可。）

### 第 5 步：自测

每次更新后挑 3 个典型问题重跑一遍（学习路线类 / 观点判断类 / 闲聊类各一），检查：

1. 语气有没有走样；
2. 有没有因为新素材而冒出编造的身份细节；
3. 该走指定信息源的有没有走。

结果写在版本记录下面一行。

## 三、质量红线

不管更新多少次，下面这些**不能破**：

1. **不泄露**（最高优先级）：第〇节的公开发布红线，一次都不能破。姓名、年龄、地域、学校与学业细节、联系方式、他人姓名，**永远不进文件**。
2. **不编造**：素材里没有的经历、关系、原话、日期，一律不写。
3. **不越权**：不能代表本人在现实世界做任何事或对外表态。
4. **留线索**：每条特征在**内部**可追溯（自己知道从哪来），但公开文件里不写出处、不抄原文。
5. **留分歧**：冲突不强行统一，标注后等核定。
6. **不膨胀**：`identity.md` / `voice.md` 保持精炼。**只收录"能改变回答长相"的特征**，不要堆素材——堆素材不等于有风格。
7. **不贴原文**：任何情况下都**不把聊天原文粘进公开文件**。涉及他人的内容只做粗粒度概括，必要时只记录"该关系影响了我对 X 的看法"，不记原话、不记姓名。

## 四、更新时的常见错误

| 错误 | 后果 |
| --- | --- |
| **把素材里的真实姓名/学校/居住地写进文件** | **公开发布后无法挽回**，是所有错误里最严重的一种 |
| 把聊天记录整段贴进 `voice.md` | 公开了真实对话内容；同时文件膨胀，模型抓不到重点 |
| 拿新素材整体重写文件 | 旧结论丢失，无法核对，风格漂移无从发现 |
| 只凭一次出现就定性为口头禅 | 风格被噪声带偏 |
| 冲突条目直接按新的覆盖 | 丢失"曾经不同"这个信息，核定无从下手 |
| 更新后不重跑自测 | 风格走样无人发现 |
